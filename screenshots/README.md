# Sweety Application Previews & Screenshots

This folder contains UI previews and feature screenshots for **Sweety – Blood Glucose Tracker**.

| Preview | Description |
|---|---|
| **01. Patient Dashboard** | Overview of daily glucose metrics, slot completion status (4/day), and Recharts trajectory |
| **02. Log & Edit Modal** | Real-time 5-rule clinical validation (40–600 mg/dl, whole numbers, no future dates, slot uniqueness) |
| **03. Readings History** | Searchable table with ADA clinical classification badges (In Range, Elevated, High, Low) |
| **04. Clinical Reports** | Daily, Month-to-Date, and Monthly reporting tabs with statistical calculations |
| **05. Neon PostgreSQL Console** | Live SSL connection inspector and runtime connection manager |

All screens are designed with an elegant lavender and white palette, deep purple primary actions, and clean tabular typography.
